# ZeroScripts

Python Script for Merging TXT Files

## merge_txt.py (`public/merge_txt.py`)

Скрипт объединяет все `.md` файлы из указанных папок (рекурсивно) в один
итоговый Markdown-файл `bibl-[YYYYMMDD-HHMMSS].md`.

### Запуск

```bash
# С указанием папок с исходными файлами (позиционные аргументы, без ключей):
python3 public/merge_txt.py /path/to/Референсы /path/to/Novells

# Справка по запуску:
python3 public/merge_txt.py --help   # или -h

# Без аргументов — используются пути по умолчанию:
python3 public/merge_txt.py
```

Пути по умолчанию для поиска:
- `/home/smirnov/Documents/AI/Нулевой/Референсы`
- `/home/smirnov/Documents/AI/Нулевой/Novells`

Выходная директория:
- Если передана ровно одна папка-аргумент — результат кладётся в корень
  этой папки.
- В остальных случаях (несколько аргументов или запуск без аргументов) —
  `/home/smirnov/Documents/AI/Нулевой/Библия`

Переменные окружения:
- `MERGE_OUTPUT_DIR` — переопределяет выходную директорию (не применяется,
  когда передана ровно одна папка-аргумент: там результат всегда в её корне).

### Правила выборки файлов

Исключаются:
- папки и файлы, начинающиеся с `_`;
- папки и файлы, содержащие `draft` в названии (без учёта регистра);
- пути и файлы внутри выходной директории (чтобы не подхватить
  собственные `bibl-*.md` от предыдущих запусков).

Дедупликация версий: если в одной папке есть несколько файлов с одинаковым
базовым именем (например, `Вечер.md`, `Вечер_(04:13_03.11.2026).md`),
выбирается самый свежий по дате в имени; приоритет — у файлов с датой.

Поддерживаемые форматы даты/времени в имени файла:

| Пример имени                 | Формат                 |
|------------------------------|------------------------|
| `Вечер_(04:13_03.11.2026)`   | `HH:MM_DD.MM.YYYY`     |
| `Вечер_(04:13 03.11.2026)`   | `HH:MM DD.MM.YYYY`     |
| `Вечер_(04.13_03.11.2026)`   | `HH.MM_DD.MM.YYYY`     |
| `Вечер_(03.11.2026)`         | `DD.MM.YYYY`           |
| `story-20240115-143022`      | `YYYYMMDD-HHMMSS`      |
| `story-20240115_143022`      | `YYYYMMDD_HHMMSS`      |
| `story-2024-01-15_14-30-22`  | `YYYY-MM-DD_HH-MM-SS`  |
| `story-20240115`             | `YYYYMMDD`             |
| `story-2024-01-15`           | `YYYY-MM-DD`           |

### Кодировки

- Входные файлы читаются с автоопределением кодировки: сначала **UTF-8**
  (в том числе с BOM — он снимается), затем **cp1251** (Windows-1251).
  Если файл прочитан не как UTF-8, это выводится сообщением
  (`🔤 имя.md: прочитано в кодировке cp1251`).
- Если ни одна кодировка не подошла, вместо содержимого вставляется пометка
  «ОШИБКА ЧТЕНИЯ ФАЙЛА» — слияние продолжается.
- Выходной файл всегда записывается в **UTF-8 без BOM**; артефакты U+FEFF
  из входного текста удаляются.
- Кириллица полностью поддерживается в именах файлов/папок и в содержимом.

### Формат выходного файла

Каждый исходный файл включается с заголовком `# <имя файла>` и указанием
пути-источника; файлы разделены горизонтальной линией `---`:

```markdown
# filename.md

*Путь: `/full/path/filename.md`*

<содержимое файла>

---

# next-file.md
...
```

### Требования

Python 3.10+ (используются аннотации `X | None` и `list[...]`), только
стандартная библиотека.
